# Chronos Engine - B2B Fleet Dispatch Demo

**Developed by:** Quintan Middle ([xNoOnex](https://github.com/xNoOnex))  
**Location:** Tucson, AZ

## Overview
This repository hosts a static frontend demonstration of the **Chronos Engine**—a custom-built, offline-first routing and invoicing toolkit designed specifically for independent 2-to-5 truck hauling operators. 

Built from the perspective of eight years of firsthand material handling and fleet operations experience, this engine eliminates the need for expensive monthly SaaS dispatch software. It is designed to function perfectly on the asphalt, even when the cell signal drops.

## Core Architecture Features
* **Zero-SaaS Infrastructure:** Operators own the app. No monthly fees, no cloud lock-in.
* **Offline-First Reliability:** Heavy reliance on local epoch timestamping ensures exact crew payouts and FMCSA HOS compliance recalculate perfectly without internet.
* **Sign-on-Glass Invoicing:** Instant local invoice generation, material tracking, and archiving.
* **Privacy by Default:** Zero telemetry or analytics tracking.
